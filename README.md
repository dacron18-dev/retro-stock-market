# Retro Market – Broker Desk
React + Vite + Supabase.
1. Supabase SQL editor: run supabase.sql (only once), then supabase-update.sql.
2. Create a broker user in Supabase -> Authentication -> Users (auto-confirm).
3. Set VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY (Vercel env vars or a local .env).
4. npm install && npm run dev
